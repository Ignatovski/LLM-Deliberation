# Expert Review Exports (Siemens-Oriented, V1)

V1 provides CSV exports to support manual expert review.

## CSV Fields

- `run_id`
- `condition_id`
- `scenario_id`
- `final_committee_label`
- `final_committee_severity`
- `final_agreement_exact`
- `transcript_reference`
- `agent_final_outputs_reference`
- `expert_label`
- `expert_severity`
- `expert_score_argument_quality`
- `expert_score_evidence_relevance`
- `expert_score_defensibility_for_report`
- `expert_would_accept_in_QA`
- `expert_comments`

## Notes

- Expert fields are blank by default for manual completion.
- Transcript and final-output references are machine-generated file paths.
